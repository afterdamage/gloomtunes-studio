# Editing

## Channel rack

Click steps to switch them on. Each row has mute (**M**), solo (**S**), volume and pan.
With the rack focused, **Up** and **Down** select a channel, **M** and **S** mute and solo it,
**+** and **-** change pattern, and **Enter** opens the channel in the piano roll.

## Piano roll

Draw notes with the draw tool (**P**), select with the select tool (**E**).

- Arrow keys move the selection; **Shift** changes length and octave, **Alt** nudges and
  changes velocity.
- **Ctrl+D** duplicates, **Q** quantizes, **M** mutes, **Delete** deletes.

## Playlist

Draw clips with **P**, select with **E**, slice with **C**. **Ctrl+D** duplicates the
selection, **M** mutes it.

## Undo

**Ctrl+Z** undoes and **Ctrl+Shift+Z** redoes. **Ctrl+Alt+Z** shows the undo history: click
any step to go back (or forward) to it.

Every key above can be changed in **Settings > Shortcuts**. Keys inside one view only work
there, so the piano roll and the playlist can use the same key for their own commands.
