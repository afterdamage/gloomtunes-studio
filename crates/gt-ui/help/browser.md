# Browser

The browser on the left finds sounds, presets, plugins and projects.

## Tabs

- **Samples**: the built-in drums, then your folders. Click a sound to hear it,
  double-click to load it into the selected channel, or drag it onto a playlist track.
- **Instruments**: Gloom, FM and wavetable synth presets, the factory ones and your own.
  Double-click one to load it into the selected synth channel.
- **Effects**: every effect and its presets. Double-click to add it to the selected mixer track.
- **Plugins**: the plugins found by the last scan.
- **Projects**: project files found in your folders.

## Searching

Type words in the search box. Every word must appear in the name, the folder, or the tags.

- `kick dark` finds files with both words.
- `120bpm` finds loops whose name says 120 BPM; `key:am` finds files in A minor.
- `#punchy` finds files you tagged *punchy*.

The search covers every folder in the folder list. Add a folder with **+**, remove it with
**×**, and use **Rescan folders** after adding files.

## Favourites and tags

Click the **☆** next to a row to make it a favourite, and the **☆** next to the search box to
show only favourites. Right-click a row and choose **Edit tags…** to tag it.

## Previewing loops in time

With **Preview at project tempo** on, a loop whose name gives its tempo ("Beat_95bpm.wav")
plays stretched to the project tempo, at its own pitch.
