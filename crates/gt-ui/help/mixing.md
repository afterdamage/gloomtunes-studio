# Mixing and export

## Mixer

Each channel plays into a mixer track (the master by default). A track has ten effect slots,
volume, pan and sends. Right-click any knob or fader to automate it or to add a modulator.

## Recording

Arm recording with **Ctrl+R**. Audio is recorded on armed playlist tracks; notes go into the
selected channel's pattern.

## Export

**Ctrl+Shift+E** exports the song (or the loop) as a WAV file, or one WAV file per track as
stems.

## Project info

**Ctrl+Shift+I** opens the project info: title, artist, genre and notes, saved with the
project.
